什麼是 n8n？為什麼要學它？
▼

n8n（讀作 "nodemation"）是一個開源的工作流自動化工具，讓你可以用視覺化的方式把不同的應用程式和服務串連在一起。你可以把它想像成一個「數位助理」——當某件事發生時（例如收到一封信），自動幫你做一連串的事（例如存到表格、發通知、回覆訊息）。

它最大的特點是可以自己架設（self-hosted），不像 Zapier 或 Make 只能用他們的雲端服務。這代表你的資料完全掌握在自己手上，也沒有執行次數的限制。

n8n 目前有 400+ 內建節點整合各種服務（Google Sheets、Slack、LINE、OpenAI...），還有 70+ AI / LangChain 節點可以直接串接大型語言模型。

💡 簡單說：n8n = 拖拉連線就能做自動化 + AI，而且免費自架無限用。

安裝方式一：Docker（推薦）
▼
最簡單的一行指令

docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n

然後打開瀏覽器 → http://localhost:5678

正式版 docker-compose.yml
  • 建立 docker-compose.yml 檔案
  • 設定 n8n image + port 5678 + volume 持久化
  • 可選：加 PostgreSQL 資料庫（正式環境推薦）
  • 可選：加 Basic Auth 保護登入
  • docker compose up -d 啟動
  • docker compose logs -f 看 log
重要環境變數
變數說明
N8N_BASIC_AUTH_ACTIVE啟用登入保護
N8N_ENCRYPTION_KEY加密憑證（32 字元）
WEBHOOK_URL外部 Webhook 網址
DB_TYPE資料庫類型（sqlite / postgresdb）
🚨 本機測試 Webhook？用 n8n start --tunnel 建立臨時公開 URL。
📦
安裝方式二：npm / 方式三：n8n Cloud
▼
npm 安裝
  • 需要 Node.js 18 以上：node -v
  • 全域安裝：npm install n8n -g
  • 啟動：n8n start
  • 或免安裝直接跑：npx n8n

macOS 權限問題？用 mkdir ~/.npm-global && npm config set prefix '~/.npm-global'

n8n Cloud
  • 到 app.n8n.cloud/register 註冊
  • 免費試用期，不需信用卡
  • 自動更新、自動 SSL、不用管伺服器
  • 缺點：有執行次數限制（付費制）

Workflow JSON 結構詳解
▼

每個 n8n Workflow 本質上就是一份 JSON 檔案。理解它的結構是後續所有關卡的基礎。

頂層欄位
欄位類型說明
name字串Workflow 顯示名稱
nodes陣列所有節點清單
connections物件節點間的連線關係
active布林是否已啟用
settings物件全域設定
每個 Node 的結構
  • id — 唯一識別碼
  • name — 節點顯示名稱（在畫布上看到的）
  • type — 節點類型（決定功能，如 n8n-nodes-base.webhook）
  • typeVersion — 節點版本
  • position — 在畫布上的 [x, y] 座標
  • parameters — 節點的設定參數
Connections 的結構

"來源節點名": { "main": [ [{ "node": "目標節點名" }] ] }

  • main 第一層陣列 = 輸出端口（大部分節點只有 1 個，IF 有 2 個）
  • 第二層陣列 = 連到的目標節點（可以一對多）
匯出 / 匯入方法
  • 匯出：點上方 ... → Download
  • 匯入：點 ... → Import from File
  • 或直接在畫布上 Ctrl+V 貼上 JSON

AI 意圖辨識 & Switch 分流

用 AI 判斷使用者要記帳、排行程還是存名片，Switch 分流到對應路徑

TIME4:00

講解內容

  • AI Agent / OpenAI 節點：串接 LLM 做意圖辨識
  • System Prompt 設計：教 AI 分類（記帳/行事曆/名片/查詢）
  • JSON 結構化輸出：讓 AI 回傳 intent + entities
  • Switch 節點：依 intent 分流到不同路徑
  • IF 節點：true / false 雙路分流（補充）
  • 錯誤處理：AI 無法辨識時的 fallback

實作演練

  • 在 W2 的 Echo Bot 基礎上加入 AI 節點
  • 設計 System Prompt：分類意圖 + 提取實體（金額、日期、姓名…）
  • 測試：傳「午餐 120 元」→ AI 回傳 intent=expense, amount=120
  • 測試：傳「週五開會」→ AI 回傳 intent=calendar, date=Friday
  • 加入 Switch 節點，依 intent 分流
  • 每條路先用 Set 節點確認分流正確

關鍵知識：AI 意圖辨識怎麼做？

用一個 AI 節點 + 精心設計的 System Prompt，讓 LLM 幫你做分類和實體提取：

  • Intent（意圖）：expense / calendar / card / query / unknown
  • Entities（實體）：金額、品項、日期、時間、姓名、公司、電話
  • Reply（回覆）：AI 同時產生確認訊息給使用者

Claude Code 是什麼？
▼

Claude Code 是 Anthropic 推出的命令列 AI 開發工具。你在終端機裡跟 Claude 對話，它可以：

  • 直接讀取、修改、建立你電腦上的檔案
  • 執行終端機指令（安裝套件、跑測試、Git 操作）
  • 理解整個專案的程式碼結構
  • 一步步幫你完成複雜的開發任務
  • 支援 MCP Server 連接外部工具（如 n8n）
💡 安裝指令：npm install -g @anthropic-ai/claude-code，然後在專案目錄輸入 claude 即可開始。
🐕
OpenClaw 是什麼？
▼

OpenClaw 是一個AI Agent 開發平台，讓你可以用 Plugin 的方式擴充 AI 的能力。

  • 安裝 Plugin 就像裝 App 一樣簡單
  • n8n-as-code 有 OpenClaw Plugin，AI 可以直接操作 n8n
  • 內建 grounding（知識基礎），減少 AI 幻覺
  • 支援多種 AI 模型（Claude、GPT、Gemini）
💡 安裝：npm install -g @openclaw/cli，然後 openclaw plugins install @n8n-as-code/n8nac
⚡
Claude Code + n8n 整合實戰
▼

最強組合：用 Claude Code 的自然語言，透過 n8n-as-code 自動建立和管理 n8n Workflow。

設定 MCP Server
  • 在 Claude Code 設定中加入 n8n-as-code MCP
  • npx n8nac skills mcp 啟動 MCP Server
  • Claude 就能搜尋 537 個節點、7,702 個模板
實際對話範例
  • 你：「幫我建一個每天早上 8 點推播天氣到 LINE 的 Workflow」
  • Claude：自動搜尋節點 → 產生 TypeScript → push 到 n8n
  • 你：「加一個判斷，下雨機率超過 50% 才推播」
  • Claude：自動修改 → validate → push

gstack 是什麼？

gstack 是一個開源的「軟體工廠」，安裝後你的 Claude Code 就擁有 23 個專業角色的 slash command。一個人就能模擬 CEO、設計師、工程經理、QA、資安長的完整團隊工作流程。

  • 作者：Garry Tan（Y Combinator 現任 CEO）
  • 授權：MIT（完全免費、開源）
  • 技術：Bun + TypeScript + Playwright
  • 依賴：只有 3 個 runtime dependency
安裝只要 30 秒：git clone --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup
